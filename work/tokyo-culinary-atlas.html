Tokyo Culinary Atlas

Designer / Developer

Tools
SQLite / Processing / Data Visualization
Focus
Tokyo food culture / international cuisine / spatial distribution

Mapping Tokyo's multicultural identity through food, geography, and interaction.

Motivation

Can we see Tokyo's cultural diversity through the geography of food?

Tokyo is one of the most culturally diverse cities in Asia, and its food landscape reflects that diversity. As a foreigner living in Japan, I became interested in how different international cuisines are distributed across Tokyo's neighborhoods and stations.

The goal was not only to count restaurants, but to make cultural distribution visible, readable, and interactive.

Data

From restaurant records to a readable visual system.

I extracted international cuisine restaurant data using SQLite and focused on 15 cuisine categories. The first version compares selected Tokyo stations; the second version uses latitude and longitude data to build a geographic Hexbin map.

Visualization Approach

The project evolved from station comparison to geographic density.

Station-based bubble map

A comparison view using familiar Tokyo station names as anchors. Circle size shows restaurant count, and color shows cuisine category.

Hexbin geographic map

A spatial density view using latitude and longitude data. Hexagons reveal broader distribution patterns across the city.

Version 1

Station-based bubble map.

Design logic

Station name at the center, cuisine categories around it, circle size as restaurant count, and color as cuisine category.

Visual System

Color as cultural signal.

Each cuisine category was assigned a color inspired by cultural or national associations. The color system helps users intuitively recognize cuisine categories while adding cultural meaning to the visualization.

Insight

Food becomes a readable urban pattern.

International cuisines form visible clusters around particular neighborhoods and transit hubs.

Station-based comparison makes cultural density readable through familiar city anchors.

The Hexbin map reveals broader geographic patterns that are difficult to notice through address lists alone.

Color and interaction help users move between data, culture, and urban storytelling.

Reflection

Data visualization can turn everyday observation into visible systems.

This project helped me understand how data visualization can transform everyday cultural observations into visible systems. By combining SQL-based data extraction, visual mapping, cultural color design, and interaction, I explored how information design can reveal hidden patterns in urban life.

I also learned that a good visualization is not only about showing data accurately, but about helping people ask better questions about the city they live in.
